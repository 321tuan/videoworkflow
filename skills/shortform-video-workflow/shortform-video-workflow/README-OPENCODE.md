# Short-form Video Workflow for OpenCode

This package contains a reusable OpenCode-compatible Agent Skill for planning high-retention short-form videos.

## Install per project

Copy this directory to:

`.opencode/skills/shortform-video-workflow/`

## Install globally

Copy this directory to:

`~/.config/opencode/skills/shortform-video-workflow/`

## Use

Ask OpenCode to use `shortform-video-workflow`, for example:

`Use the shortform-video-workflow skill to turn this source into a 35-second TikTok production brief.`

The skill does not require a specific model or connector. It uses browsing, file inspection, asset search, or rendering only when those tools exist in the user's OpenCode environment.

See `references/opencode-install.md` for more examples.
