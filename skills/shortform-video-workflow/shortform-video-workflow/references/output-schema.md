# Production Brief Output Schema

Use this structure by default. Omit sections that are genuinely irrelevant.

# Short-form Video Production Brief

## 1. Objective
- Audience:
- Platform:
- Core proposition:
- Desired viewer action:
- Target duration:
- Assumptions:

## 2. Fact sheet
| Claim | Status | Evidence/source | Use in video? |
|---|---|---|---|

Allowed status values: `verified`, `user-provided`, `inferred`, `unverified`.
Never present inferred/unverified quantitative claims as established fact.

## 3. Candidate hooks
Provide 8-12 hooks, grouped by hook type. Mark one as the default and briefly state why it matches the body/evidence.

## 4. Narrative architecture
Write the final sequence in one line, e.g.:
`Pain -> contradiction -> proof -> mechanism -> payoff -> CTA`

## 5. Beat sheet
| # | Time | Function | Voice | Subtitle | Hero text | Visual type | Visual direction | Asset/source | Perceptual event |
|---:|---:|---|---|---|---|---|---|---|---|

Keep each row production-oriented. Avoid prose that an editor cannot act on.

## 6. Full voice-over
Provide the final continuous VO script.

## 7. Asset manifest
| Asset | Priority | Exact need | Source/provenance | Status |
|---|---|---|---|---|

Priority order: first-party/product, evidence/source, exact external asset, custom motion, generated asset, generic stock.

## 8. Motion and editing notes
Specify pacing, typography emphasis, transition logic, subtitle behavior, audio cues, and any beat that intentionally slows down.

## 9. CTA
State one primary CTA. Add alternatives only when the user explicitly wants variants.

## 10. QA report
Report failures or warnings from the QA checklist. Do not hide weaknesses.
